# सत्य दर्पण – हिन्द की कविताएँ

यह वेबसाइट **हिन्द की कविताओं** का डिजिटल संग्रह है।

## फाइलें

- `index.html` – मुख्य पेज
- `style.css` – डिज़ाइन
- `script.js` – कविताएँ और इंटरैक्शन

## GitHub Pages पर होस्ट कैसे करें

1. GitHub पर नया रिपॉजिटरी बनाएँ नाम से: **sdsatyadarpan**
2. इन तीन फाइलों (`index.html`, `style.css`, `script.js`) को अपलोड करें
3. Settings → Pages → Source में **main** branch चुनें
4. कुछ मिनट बाद आपकी साइट इस पते पर लाइव हो जाएगी:

   **https://आपका-यूजरनेम.github.io/sdsatyadarpan/**

## नई कविता कैसे जोड़ें

`script.js` फाइल में `poems` ऑब्जेक्ट में नई कविता जोड़ें, और `index.html` के poems-grid में नया कार्ड बनाएँ।
